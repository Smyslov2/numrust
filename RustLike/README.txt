RustLike - прототип в духе Rust (Win32 + OpenGL, без внешних библиотек)

СБОРКА EXE (любой из вариантов):
 1) GitHub: залейте папку в репозиторий -> Actions -> build-exe -> скачайте RustLike.exe
 2) Visual Studio: "x64 Native Tools Command Prompt" -> build_msvc.bat
 3) MinGW-w64: build_mingw.bat

УПРАВЛЕНИЕ: WASD, Shift - бег, Ctrl - присесть, Space - прыжок,
ЛКМ - бить/использовать, E - пить из воды, 1-4 - слоты, Esc - выход.
